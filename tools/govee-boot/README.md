# Govee 开关机自动灯光

独立 Windows 后台服务：正常开机时自动发现局域网 Govee 设备，设置 5400 K 白光、100% 亮度并打开；正常关机或重启时关闭本次开机发现的设备。运行期间无窗口、无托盘图标，无需云端账号或 API Key。

## 安装

1. 解压完整 ZIP。先在 Govee Home 中启用设备的 LAN Control，电脑和灯带应处在允许互访的同一局域网。
2. 双击 **Install.cmd**，允许一次管理员授权。安装后会立刻启动服务并尝试开灯。
3. 此后由 Windows 自动启动服务，不需要登录，也无需添加启动文件夹项。

安装会注册服务并添加专用/域网络的 UDP 4002 入站规则，因此需要管理员权限；日常使用低权限 LocalService 账号，不关闭防火墙，也不修改公网网络规则。

- 程序和配置：`%ProgramFiles%\RetroDuetLighting\`
- 日志与本次发现记录：`%ProgramData%\RetroDuetLighting\`
- 安装失败日志：`%TEMP%\RetroDuetLighting-Install.log`

## 运行方式

- 开机最多等待网络/设备 120 秒。每次短暂绑定 UDP 4002；如果端口被屏保或其他控制器占用，稍后重试。
- 一轮扫描发现设备并设置白光后，释放端口并休眠，不持续轮询，不覆盖屏保的颜色。
- 若一直未发现设备，到时也进入休眠；下次启动服务/电脑再尝试，不追踪等待期结束后才上线的设备。
- 关机处理 Windows preshutdown 预通知，尝试在网络服务停止前关灯。使用临时发送端口，不抢占 4002，重复发送约 2 秒后退出。
- 手动停止或卸载服务也会关闭本次发现的灯。服务只在开机/服务启动时设白光，不会在屏保半小时关灯后重新点亮。
- 普通睡眠/休眠和唤醒不额外改灯。Windows 快速启动路径尚未实机验证。

## 限制设备

默认控制发现的全部 Govee LAN 设备。以管理员身份编辑安装目录下的 settings.json：

```json
{
  "DeviceIps": ["192.168.1.23"],
  "DiscoverySeconds": 120
}
```

DeviceIps 为空数组表示接受全部设备；非空时仍要发现对应 IP 才操作。等待时间允许 10～600 秒。修改后重启服务生效，会重新执行开灯。建议在路由器保留灯带 DHCP 地址，避免使用期间 IP 变动导致关机指令找不到设备。

## 与屏保同时使用

服务完成启动扫描后不占用屏保端口，不持续争抢颜色。配套屏保兼容版会在关机期间读取服务的短期标记，将退出恢复白光改为关灯；普通退出仍恢复白光。已发布 v3.6.4 尚无这项配合，建议更新到v3.6.5 或更新版本。

## 卸载

双击 **Uninstall.cmd** 并允许管理员授权。删除服务、防火墙规则和服务 EXE，保留配置与日志；无需重启。

## 构建与验证状态

源码目录运行 build.ps1，使用 .NET Framework 自带 csc 编译，无第三方依赖，源码随包提供。

仅完成编译和打包，未安装服务、操作真实灯带或触发重启/关机验证。UDP 不保证交付；断电、强制关机、设备离线或网络提前中断时无法保证关灯。关机通常额外约 2 秒，不无限等待离线灯带。

协议：[Govee 官方 LAN API](https://app-h5.govee.com/user-manual/wlan-guide)。预关机机制：[Microsoft 服务控制处理说明](https://learn.microsoft.com/en-us/windows/win32/services/service-control-handler-function)。
