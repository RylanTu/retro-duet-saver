# Retro Duet Saver v3.6.0

## 交互与动画

- 连续鼠标移动、悬停、按下/松开与控件状态同步，计算器保留 1984。
- 字号、字体、下划线、图标、字符映射、控制面板、图案和绘图补齐内容反馈。
- 修复 19 / 21 滑块残影、20 图案点击无变化、8 下划线偏高；减轻 18 网格边框并增加 @42 选择操作。
- 16 的 DOS 彩蛋：逐字输入 rm -rf /，显示 Bad command or file name 后返回提示符；仅为画面演出。
- 材质与状态后台预载；提供快速和正常速度检查入口。

## 下载使用

解压 ZIP，运行 RetroDuetSaver.exe；Screensaver.cmd 进入多屏屏保。Review-Quick.cmd 和 Review-Normal.cmd 可逐场查看；PgDn / PgUp 切场，Home 重播。

已完成 38 场景离线更新与预热画面检查，以及连续轨迹、点击提交状态、状态图像差异和后台缓存检查。未完成多屏硬件呈现帧率的系统性验证。编译仍有两条已有的未使用字段警告。
