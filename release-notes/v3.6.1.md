# Retro Duet Saver v3.6.1

- 调整 Mac 时钟布局与固定字位，轻微提亮原有配色。
- 按参考视频追踪 25×32 点阵的笑脸麦金塔；启动场景采用连续棋盘背景，消除矩形边界。
- Windows 画图改为逐笔绘制四格旗标与拖尾。
- 首场保留随机系统的时钟；后续排除上一场，从其余 37 场景中等概率抽取。
- 使用原生子窗口承载系统设置页预览；父窗口销毁后终止预览，防止脱离设置页。
- 严格解析屏保参数，无效预览不回退到普通窗口；直接打开 SCR 显示配置。
- 增加不依赖窗口焦点的输入退出检测。

已做启动参数、随机分布、输入退出策略、预览父窗口销毁/重建与无效父句柄检查。Windows 设置页实际应用流程仍需实机确认。
