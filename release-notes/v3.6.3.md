# Retro Duet Saver v3.6.3

- 场景平移、旋转和推近采用平滑曲线；滑入/滑出额外位移在衔接处的速度、加速度归零。
- 减小滑入/滑出幅度，保留原有退场方向逻辑。
- 帧率调度改为累计单调时钟时间额度，减少迟到回调造成的额外跳帧；暂停和恢复时重置额度。

## 实测与限制

同机 240Hz 屏幕、设置 120 帧、窗口模式，约 10 秒有效采样：

| 场景 | 原 UI 回调/秒 | 新 UI 回调/秒 | P95 间隔变化 |
| --- | ---: | ---: | --- |
| 时钟 | 88.44 | 111.49 | 24.912 → 21.435 ms |
| 属性页 | 93.71 | 113.76 | 23.604 → 21.477 ms |

这是 UI 提交节奏，不是 GPU 实际呈现帧率。仍存在长帧；结果受设备和系统负载影响，不代表所有场景或多屏表现。更新次数增加时 CPU 总开销可能上升。

本次为标准 SDR 版，不包含 HDR 实验代码或已撤回的像素缩放转场。
