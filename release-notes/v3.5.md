# Retro Duet Saver v3.5

Macintosh × Windows 95/98 像素动态屏保，运行于 Windows 11。

## 下载

下载 RetroDuetSaver-v3.5-windows.zip 并解压，运行 RetroDuetSaver.exe。Preview.cmd 为窗口预览，Screensaver.cmd 为多屏屏保，Settings.cmd 打开设置。右键 RetroDuetSaver.scr 可安装到 Windows 屏保列表。

## 内容

38 个场景条目；时钟开场和加权随机；双系统消散浮现过渡；拖动、点击、绘图、签名输入及回形针；多屏共享场景缓存。完整功能与快捷键见 README。

## 说明

面向 Windows 11 x64 / .NET Framework 4.x。可设 60、120、144 FPS 上限，实际性能取决于硬件与显示配置；混合 DPI 和多屏组合尚未全面验证。发布文件未做代码签名。音乐、参考视频与含商业音乐的宣传片不随本包发布。

SHA256SUMS.txt 可用于检查 ZIP 完整性。
