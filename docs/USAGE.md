# 安装与使用

## 环境

主要面向 Windows 11 x64；使用 .NET Framework 4.x、WPF、WinForms 及 Windows GDI。其他 Windows 版本尚未验证。无需安装其他字体，也无需联网运行。

## 便携预览

解压 Release ZIP 到固定目录，运行 RetroDuetSaver.exe 或 Preview.cmd。预览默认随机播放；F11 或 Enter 全屏，Esc 退出。设置通过 S 或 Settings.cmd 打开。设置文件保存到：

```text
%LOCALAPPDATA%\RetroDuetSaver\settings.xml
```

需要重置时，先退出程序，再删除该设置文件。

## 设置为系统屏保

1. 将解压目录放在准备长期保留的位置。
2. 右键 RetroDuetSaver.scr，选择“安装”（Windows 11 可能需要先点“显示更多选项”）。
3. 在 Windows“屏幕保护程序设置”中选择该屏保，调整等待时间并应用。
4. 需要恢复时输入 Windows 凭据，可勾选“在恢复时显示登录屏幕”。

无需把文件复制到系统目录。移动或删除安装目录后，需要重新选择屏保路径。

仅立即体验多屏效果，可运行 Screensaver.cmd。该模式约有 1.5 秒启动保护期，之后移动鼠标、点击或按键即退出。屏幕中的鼠标演出由程序驱动，不会接管真实系统光标去操作其他软件。

## 预览快捷键

| 按键 | 功能 |
| --- | --- |
| F11 / Enter | 切换全屏 |
| Esc | 退出 |
| Space | 切换配色 |
| A | 切换自动鼠标演出 |
| P | 暂停 / 继续 |
| S | 设置 |
| F2 | 帧率与性能叠层 |

## 常见问题

- **高分辨率或多屏较慢**：先将目标帧率调为 60，再观察差异。目标上限不等于实测帧率。
- **竖屏或超宽屏看不到完整窗口**：当前采用保持比例、居中裁切，各屏共享场景，并非把桌面拉伸到完整虚拟桌面。
- **屏保里按快捷键直接退出**：快捷键用于普通预览；屏保模式按键即退出。
- **Windows 提示发布者未知**：当前发布文件没有代码签名；可从源码自行构建。不要将关闭系统安全防护作为安装步骤。
- **中文正文或任意长文字**：当前像素字形及布局面向项目内置内容，没有完整的多语言排版支持。

卸载时先在 Windows 设置中选择其他屏保或“无”，再删除解压目录；需要清除个人设置时另行删除上面的设置目录。
