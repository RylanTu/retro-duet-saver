# 磁盘缓存试用版

缓存目录：`%LOCALAPPDATA%\RetroDuetSaver\Cache\<构建标识>`。
第一次遇到场景时自动生成；再次出现或重新启动时从磁盘读取。构建标识隔离不同版本，损坏或缺失的文件自动回退生成。可在程序退出后删除 Cache 目录释放空间。

## 已接入

- ReferenceContent 场景底图、固定交互状态图：无损压缩像素数据，保留透明度、分辨率和 DPI。
- ReferenceMotion 固定演出：鼠标、滑块、绘图进度、计算器按键和输入状态的时间采样；连续位置插值，跨点击/释放等离散边界时用原算法精确求值。
- 内存中仍只保留两张底图和当前场景的交互状态，其余图层保留在硬盘。
- 实时时钟继续更新，配色、镜头和转场继续实时合成。

新增原生场景缓存：

- Mac / Windows 独立签名：磁盘保存每个字符的像素格、位置和输入时间点；每种已输入长度的冻结几何在内存中复用，多屏共用。无需每帧遍历输入文本或在下一轮重新生成字形。
- Windows 画图：磁盘保存固定鼠标轨迹（含抬笔状态）和带阴影的笔触模板，保持原有增量更新。
- Mac 图案编辑器：四种交互状态的完整透明图层存入磁盘。

原生场景的滑块、拖动窗口仍按进入场景时的实际位置计算；点击、重弹和光标闪烁保持实时状态。简单插值仍直接计算，没有为它增加逐帧磁盘读取。此版并非将全部原生动画录制成帧序列；GPU 的镜头、配色与合成开销仍存在。

## 验证

CacheChecks 对 96000 个采样检查全部离散状态，鼠标最大位置误差 0.032667 逻辑像素。无损像素往返、损坏文件回退通过。
同一测试构建、独立进程的首次 / 再次加载：Mac 控制面板 298.3 / 37.4 ms，Windows 显示属性 228.9 / 22.7 ms，控制面板选中状态 51.1 / 3.8 ms。首次包含生成及写入，数据是本机单次对照，不代表实际 FPS 提升。

诊断时设置 `RETRO_DUET_CACHE=0` 可禁用磁盘和轨迹缓存；`RETRO_DUET_CACHE_DIR` 可指定测试缓存目录。

本轮额外验证：76 个签名前缀与原有像素几何完全一致，逐字时间边界一致；Windows 画图轨迹逐点一致。冷缓存与新进程热缓存均通过。
