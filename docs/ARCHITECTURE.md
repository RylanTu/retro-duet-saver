# 渲染与性能

## 场景调度

DuetApp.cs 中 SharedView 负责两种风格的公共画布、镜头、颜色、过渡和鼠标。随机模式先选时钟，再以 35% 概率选时钟；其余场景从对应系统的候选集合中选择，避开近期重复。38 个条目不代表每个窗口都能手动操作。

## 像素与动态内容

MacReferenceFonts.cs 提供内置像素字形；WinWindowsPixels.cs 从本机 Windows 字体生成像素字形。静态场景通过 ReferenceContent 生成并复用冻结位图，缓存数量有界。时钟、计算器数值、文档输入与鼠标演出单独更新。

整体仍存在逐帧镜头变换、颜色合成和 WPF 合成开销；静态内容缓存不能消除这些开销。暂停、最小化和设置期间会调整渲染调度。不要将离线宣传片的 60 FPS 当作实机性能数据。

## 多屏

MultiScreenSession 只创建一份 SharedView。主屏承载公共源场景，其他屏幕通过 BitmapCacheBrush 复用；多屏时开启源缓存。缓存缩放考虑屏幕大小、DPI 与硬件纹理上限；软件渲染限制缓存规模。显示配置变更采用 350 ms 防抖后重建窗口。

各屏通过 UniformToFill 保持比例并裁切，当前是同步镜像场景，不是每屏独立抽签，也不是横跨桌面的全景。多屏支持使用系统 DPI 感知；混合 DPI、热插拔及不同刷新率组合仍需更多实机覆盖。

## 性能报告

程序预览按 F2 可查看指标。报告卡顿时请提供 Windows 版本、GPU、显示器分辨率/缩放/刷新率、屏幕数量、目标帧率、具体场景以及复现步骤。项目没有宣称全硬件稳定 144 FPS 或零额外多屏开销。
