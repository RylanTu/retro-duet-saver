# Govee 局域网灯带联动

本功能为可选项，**默认关闭**。在设置中勾选“Govee 灯带随屏保变色（可选）”并保存，下次启动正式屏保（`Screensaver.cmd` 或 `.scr /s`）时启用。未勾选时不创建控制器、不扫描局域网、不操作灯带。不需要 API Key、账号或云端服务。普通窗口预览、系统设置预览、交互检查和视频导出不操作灯带。

## 使用前

1. 在 Govee Home 中将设备连上 Wi-Fi，并打开设备设置中的 **LAN Control / 局域网控制**。
2. 电脑和灯带处于同一个允许设备互访的局域网。访客网络的设备隔离会阻止发现。
3. 如 Windows 防火墙提示，请允许本程序在专用网络通信。程序接收 UDP 4002，向组播 `239.255.255.250:4001` 发现设备，向设备 UDP 4003 发控制命令。
4. 同一电脑不要同时运行其他占用 UDP 4002 的 Govee 控制器。端口占用时本功能停止，屏保正常运行。

协议来源：[Govee 官方 LAN API 手册](https://app-h5.govee.com/user-manual/wlan-guide)。仅支持该协议能发现和控制的设备；蓝牙设备及未启用 LAN 的设备不会响应。

## 行为

- 从正式屏保启动开始计算实际经过时间，暂停动画、切换场景和显示器重建不重置计时。
- 启动时扫描所有活动 IPv4 网卡，前几秒重试，随后每 30 秒扫描一次。因此稍后上线的设备也可加入。
- 启用后默认控制所有发现的 Govee LAN 设备。新发现设备设为经过饱和度增强的背景色并打开；联动期间不修改设备原有的全局亮度。
- 设置中的“灯带饱和度”可调 0～300%，默认 165%；0% 为灰度、100% 为原始背景色，数值越高越浓郁。颜色保留背景色相与 RGB 峰值亮度，并限制在有效范围；中性灰保持中性，不修改屏保画面颜色。保存后下次启动正式屏保生效，未启用灯带联动时该滑块禁用。
- 一套控制器跟随多屏共享画布的背景颜色，以最多约 10 Hz 发送 RGB，额外使用约 250 ms 平滑跟随。静态颜色不逐帧发送，仅每 2 秒维持一次。网络收发、解析和扫描均在后台线程，不读取屏幕截图、不增加逐帧网络任务。
- **未满 30 分钟退出**：设为 5400 K 白光、100% 亮度，并确保开启。
- **达到 30 分钟**：关闭已发现设备并结束本次联动；之后退出保持关闭，不重新亮起。重新启动屏保才开始新的一次计时。
- 结束状态重复发送三次，降低 UDP 丢包概率。UDP 不保证交付；设备断电、断网或系统强制结束进程时，无法保证恢复指令执行。屏保不启动常驻服务。

## 可选限制

若家里有多个 Govee 设备，只想控制指定灯带，可在启动程序前设置环境变量（逗号分隔 IP）：

```powershell
$env:RETRO_DUET_GOVEE_IPS = '192.168.1.23,192.168.1.24'
& .\RetroDuetSaver.scr /s
```

固定 IP 建议在路由器设置 DHCP 地址保留。不设置该变量即接受所有被发现设备。

设置 `RETRO_DUET_GOVEE=0` 可关闭此功能。环境变量需要由屏保启动进程继承；如需对 Windows 自动屏保生效，请设置用户环境变量并重新登录 Windows。

简要发现与错误日志：`%LOCALAPPDATA%\RetroDuetSaver\govee-lan.log`。日志中的“恢复/关闭”记录表示已尝试发送指令，不表示设备已确认执行。日志自动限制大小。

## 验证状态

代码已接入正式多屏屏保路径。未在用户真实灯带上验证发现、色彩还原或色温支持，实际结果还取决于设备固件、型号和局域网配置。

## 开关机自动灯光

需要在电脑开机时设白光、关机时关灯，可单独安装 [开关机灯光服务](https://github.com/RylanTu/retro-duet-saver/blob/main/tools/govee-boot/README.md)。屏保 v3.6.5 起识别服务写入的关机标记，避免退出恢复白光覆盖关机指令；普通退出行为不变。
